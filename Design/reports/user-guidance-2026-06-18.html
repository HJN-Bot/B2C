SpeakSpark · User Guidance

怎么用、前后端怎么串

一页讲清：练习一遍走完的流程、每个页面怎么操作、哪些跑在本机、哪些要后端，以及 AI 是怎么连上去的。

01一次练习的完整闭环

用户从首页出发，一条线走到结束页，再回到 My 沉淀。

Home 选模式/话题→ Practice 开口说→ 实时字幕 + 猫教练 + KTV→ 停顿 → AI 追问→ End→ Takeaway 复盘→ My 历史/短语/成长

02每个页面怎么操作

① Home 首页

  • 选 Practice Mode（Free Talk / Exam Prep / Story）——决定教练风格。
  • Today's Starter：「Use this topic」用推荐话题，或「My own」自带话题。
  • 本周 Trying Point 卡：一句"这次就试这一个"，点它直接进练习。
  • 底部导航：Start / Practice / Takeaway / My，四页互通。

② Practice 练习页

  • 点 Start Practice 开始（需 Chrome/Edge + 允许麦克风）。
  • 说话时：字幕逐行上滚、当前句居中；KTV 四项里得分的会亮、没动静的变灰。
  • 停顿约 2.5 秒：猫下方弹出一个针对你刚说内容的小问题/提示 →「Use it」继续或「Skip」。
  • 随时点右上 End 结束 → 进 Takeaway。

③ Takeaway 结束页（自上而下）

  • ① Your run：一句鼓励 + 你做得好的一点（带原文引用）。
  • ② Level up：放大 / 改掉 / 下一次怎么说（= 你的下一个 Trying Point）。
  • ③ Your run in detail：讲了什么、更多做得好、四项进步分。
  • ④ Coach：追问框（presets 如「Ask me one question」，不替你作答）+ Practice Again。

④ My 我的

  • Trying Point / Practice growth（成长）/ Practice history（右上日期图标按 All/Week/Month 筛选）。
  • Settings：Coach mode（信任边界，信息）· Saved phrase bank（点开看存过的短语）· Coaching prompt（点开可写自己的教练指令，会注入 AI）。

03前端 ↔ 后端怎么串

前端不直连 Gemini；所有 AI 调用走 Supabase Edge Function 代理，把密钥藏在服务端。

前端→ Supabase Edge Function gemini-proxy→ Gemini（密钥在服务端）→ 返回 JSON → 前端渲染
能力现在跑在哪
实时字幕（语音转文字）本机 浏览器 SpeechRecognition，不依赖后端
实时教练 / 停顿追问 / Takeaway 总结 / Chat需后端 走 gemini-proxy → Gemini
历史 / 短语库 / trying point / prompt 偏好本机 localStorage（单设备，未绑定用户）
音频录音回放 / 跨设备 / 账号绑定需后端 需 Auth + Supabase Storage + 数据表（尚未做）

⚠️ 当前：AI 不可用。Supabase 后台 jyofoabobuwfowpctbfd 已失效（域名不解析），所有 AI 调用在网络层失败 → 自动回退到本地占位（Takeaway 会出现诚实提示条）。前端一切正常。

04恢复 AI / 本地运行

本地跑前端

  1. 项目目录执行 npm run dev。
  2. 打开 http://localhost:5173/#/（路由要带 #）；Chrome/Edge + 允许麦克风。

让 AI 真正连上（需后端）

  1. 在 Supabase 控制台恢复 jyofoabobuwfowpctbfd，或新建项目。
  2. 新建的话：更新 src/integrations/supabase/client.ts（URL + anon key）与 supabase/config.toml（project_id）。
  3. 部署函数：supabase functions deploy gemini-proxy（另含 analyze-voice / get-gemini-api-key）。
  4. 配密钥：supabase secrets set GEMINI_API_KEY=…。
  5. 回前端点 Try again；Takeaway 的诚实提示条消失即代表 AI 通了。
