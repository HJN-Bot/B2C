外部 reviewer 文字反馈 #1–#5

来源：试用反馈原话。这五条共同指向一个原则——「说话中的界面，只放帮用户继续说下去的东西」。

#1

字幕改为单行 Karaoke，End 按钮固定

已上线

原问题

多行字幕信息过载、用户分心；多人噪音环境下实时转录抖动，右上角 End 按钮被挤开点不到。

"keep the transcript to one line… the 'end' button keeps getting bumped and cannot be clicked"

我们怎么改

字幕改成提词器式：连续记录、当前句锁在中间一行、旧句上滚淡出、固定高度不再越说越长。End 按钮固定在顶栏，不随字幕内容移动，始终可点。

#2

去掉音浪等冗余动效

已上线

原问题

音浪（40 柱 Canvas）+ 字幕 + AI 气泡 + KTV 四指标 + 暂停卡，动态元素太多，喧宾夺主。

"consider not showing the 'voice wave'… a lot of moving elements… a bit distracting"

我们怎么改

砍掉大音浪动效；猫只画猫、并排气泡删除；多处重复的 listening 文案合并，状态只在猫下方一个固定槽位显示，切换不跳动。

#3

说话中显示话题提示 + 冷启动关键词

已上线

原问题

开口时冷启动忘话题细节、说着说着断线，尤其科技/科学类话题对中学生本就不熟。

"showing the topic at the top… they could run into a cold start and not remembering all the details"

我们怎么改

顶部常驻 🎯 当前话题 / 模式；冷启动给关键词小标签，讲到哪个就自动变绿，形成"我讲到了"的成就感。

#4

结束页自上而下 + 原文引用证据

结构已上线 · AI 内容受后台影响

原问题

建议和用户实际说的内容脱节，看不到"因为我说了这句、所以建议那样"的因果链。

P1

Cover · 核心原则与红线

部分

原则 / 红线

UI 不能读成评分/评判/比赛；只做 coach process（prompts / frames / vocabulary / 一个 next-run plan）；避免完整演讲、比分、排名、实时纠错、暴露 AI provider 报错。

我们怎么落

Takeaway 常驻 "practice feedback only" 信任标签；说话中不弹比分式评价；AI 报错改为中性诚实提示（不再红色"失败"、不暴露 provider）。🟡 把该标签推广到全 app 仍待办。
