# PRD — SpeakSpark 英语口语科普演讲练习平台

**版本**: v0.4  
**日期**: 2026-04-27  
**状态**: Sprint 1 完成，Sprint 2 体验契约锁定中

---

## 1. 产品概述

### 1.1 产品定位

SpeakSpark 是一款面向 **6–9 年级初中生（11–15 岁）** 的英语口语科普演讲伴练平台，专为科普演讲竞赛场景设计。

核心体验哲学：**零摩擦开口 → 被看见、被听见 → 高光被捕捉 → 越练越上瘾**。

不是考试工具，是练习伴侣。

### 1.1.1 实时 AI 体验原则（Sprint 2 锁定）

SpeakSpark 的实时体验必须让学生明确感到：**AI 正在听我的声音，而不是等我说完以后读一段文字报告**。

因此拆成三条并行链路：

| 链路 | 目的 | 输入 | 延迟目标 |
|------|------|------|----------|
| 即时可见链路 | 音浪 + 字幕立刻响应，制造"它在听我" | 麦克风音频流 + 浏览器实时字幕能力 | < 300ms |
| 实时理解链路 | AI 气泡、内容相关追问、自动高光 | 滚动音频片段（主输入）+ 当前字幕状态（辅助上下文） | 1.5–3s 内有反应 |
| 结束总结链路 | 完整转录、润色版练习稿、juicy 下一步建议 | 完整录音 + 完整 transcript | session 结束后 |

字幕不是 AI 分析的唯一来源，也不能成为实时体验的阻塞点。Gemini/实时模型必须直接拿音频片段做理解；字幕只是同步状态、可视化反馈和上下文辅助。

### 1.2 核心价值主张

| 角色 | 痛点 | SpeakSpark 解决方案 |
|------|------|---------------------|
| 学生 | 开口之前有心理门槛 | 零设置，打开即说 |
| 学生 | 说着说着就卡壳、不知道继续 | 卡壳时温柔接力（Follow-up 卡从底部滑入） |
| 学生 | 不知道自己哪里说得好 | 好的表达被实时高光捕捉，积分爆炸动画 |
| 学生 | 练了就忘，没有积累感 | 高光自动沉淀素材库，生成可跟读语音包 |
| 学生 | 缺乏持续练习的动力 | KTV 式多维积分 + 成就解锁 + 连续打卡 |
| 教师 | 难以逐一指导 | 练习报告 + 高光片段回放（二期） |

### 1.3 竞赛背景

组委会命题范围内，学生自选科普主题，用英语完成演讲/辩论/探究展示。个人或团队现场时间不超过 **5 分钟**，全程英语口语。SpeakSpark 聚焦于帮助学生把碎片化的想法，练成流畅自信的 5 分钟演讲。

### 1.4 竞品分析（2026-04-27 完成）

| 竞品 | 解决的核心痛点 | 核心优势 | 用户前5步 | 关键弱点 |
|------|--------------|---------|---------|---------|
| **ELSA Speak** | 发音不准、缺少即时反馈 | 音素级 AI 纠正，离线可用 | 下载→录音→评分→音素拆解→重试 | UI 像医院，无游戏化，初中生易放弃 |
| **Yoodli** | 没有人帮我练演讲 | 深度 AI 分析（语速/填充词） | 录制→转录→数据报告→对比历史→AI 建议 | 职场向、复杂、无激励机制 |
| **Speeko** | 演讲焦虑，不知从何练起 | 结构化课程 + 教练式引导 | 测评→个性化计划→日练→进度→徽章 | 非实时、要订阅、不够酷 |
| **Duolingo** | 没有持续学语言的动力 | 世界级游戏化（连续打卡/XP/联赛） | 设目标→每日课→XP→连续火焰→成就 | 口语练习浮于表面，无演讲专项 |
| **Cake** | 无法自然开口说话 | 原声视频跟读 + 录音对比 | 选视频→听→跟读→录音→和原声对比 | 被动消费，无实时 AI，内容固定 |

**SpeakSpark 的白色地带**：市面上没有同时做到「高光即时捕捉 + KTV 多维实时积分 + 科普演讲竞赛专项 + 专为中国 K-12 学生设计」的产品。

## 2. 目标用户

### 2.1 主要用户：6–9 年级备赛学生（11–15 岁）

- 有手机，可以自己独立完成练习
- 碎片化练习习惯，每次 5–15 分钟
- 对即时正向反馈极度敏感（失去反馈 → 30 秒内放弃）
- 强烈需要"我很厉害"的身份认同，而非"我在做功课"的感觉

### 2.2 用户画像

**李诺（15岁）· 备赛高手**  
英语好，但演讲时容易卡词，散乱的想法难以组织成 5 分钟连贯演讲。被认可感对他极重要，高光捕捉是核心吸引力。

**陈梦（12岁）· 努力追赶者**  
口语薄弱，词汇量有限，说几句就停下来。需要大量引导和鼓励才能建立开口信心。跟读自己的好句子对她来说新奇且有效。

### 2.3 初中生用户心理 + 前 5 步旅程

**关键心理特征：**

| 特征 | 设计响应 |
|------|---------|
| 即时满足（< 2s 需要第一个正向反馈） | 音浪在点击后立刻律动 |
| 身份认同（"我英语还挺好的"） | 高光捕捉 + 积分 = 看得见的成就 |
| 手机原生（拇指操控、竖屏、深色背景） | Mobile-first，深色主题，大按钮 |
| 低挫败容忍（30s 内不懂就走） | 零引导页，打开即录音 |
| 连续打卡心理（"不能断"） | 首页最显眼位置放 Streak 🔥 |

**前 5 步用户旅程（初中生）：**
1. 打开 → 感受到"这不像学习，这很酷"（深色渐变 UI + 音浪）
2. 看到自己名字 + 今天第 N 天 → "有被记住的感觉"
3. 看到上次的"名句高光" → "那是我说的，我很厉害"
4. 点 Start Speaking → 0 摩擦，立刻开始录音
5. 第一个音浪动起来 → **"它在听我说话！"** ← 第一个 Wow Moment

### 2.4 设计原则（针对 6–9 年级）

| 原则 | 具体体现 |
|------|---------|
| 深色背景（TikTok/Spotify 语境） | `#0B0C1E` → 深蓝黑渐变，绝对不用白底 |
| 超大点击目标 | CTA 按钮最小高度 56px，拇指可轻松触达 |
| 动画要有分量感 | 高光爆炸：金色粒子 + 积分跳动，而不是细微过渡 |
| 固定 3 分钟默认时长 | 降低心理压力，而非开放式"随便练多久" |
| 每次必有收获 | 每个 session 至少触发 1 次高光（算法兜底） |

## 3. 三页极简用户旅程

### 旅程总览

```
[Page 1: 首页 /] ──→ [Page 2: 练习房间 /practice] ──→ [Page 3: 结束页 /session-end]
   一键开口              实时伴练体验                       高光回顾 + 素材沉淀
```

> ⚠️ 红线：不增加话题选择页、模式选择页、时长设置页。零选择负担是核心设计原则。

---

### Page 1：首页（Home）

**设计原则**：最短路径到开口说话，零选择负担。

**内容**：
- 顶部：SpeakSpark logo + 设置入口
- 打招呼区：Hey [Name] 👋 + 今天第 N 天 🔥
- 数据卡：Streak 天数 + Level XP 进度
- 高光预览：上次高光片段（迷你波形 + 引文 + 分数 + 播放按钮）
- 成就徽章区：4 个成就的解锁状态
- 底部大按钮：**"Start Speaking 🎙️"**（渐变色，带光晕）

**不要**：话题选择 / 模式选择 / 时长设置

---

### Page 2：练习房间（Practice Room）— 核心体验

**进入即录音**，全屏沉浸式界面。

```
┌────────────────────────────────────────┐
│  [KTV 积分条]  🌊 Fluency ████░░       │  ← 顶部，始终可见
│               📚 Vocab  ███░░░        │
│               🧠 Logic   ████░░        │
│               ⏱️ Duration ██░░░        │
├────────────────────────────────────────┤
│  "Artificial intelligence is..."       │  ← Karaoke 字幕，两行内滚动
│                                        │
│   🎙️ Listening...                      │  ← 状态文字
│      ▁▂▄▇▄▂▁  ▁▂▄▇▄▂▁  ▁▂▄▇▄▂▁       │  ← Canvas 音浪，无突兀白框
│                                        │
│   💬 "You mentioned renewable energy" │  ← 内容相关 AI 气泡
│                                        │
│   [⚡ Mark Highlight]  ← 手动打高光     │
├────────────────────────────────────────┤
│  ⭐ 3 highlights  │  02:34  │  [End]   │  ← 底部控制栏
└────────────────────────────────────────┘
```

**卡壳触发时**（沉默 ≥ 4s）：
```
底部滑入卡片 ──→ "💡 You mentioned renewable energy. Can you give one real-world example?"
              ──→ [Got it ✓]  [Skip]
```

**高光捕捉时**（自动检测 or 手动打标）：
```
金色光晕爆炸 + "+22 ⭐  Great use of evidence!" 从中心弹出 (1.5s 后消失)
```

**KTV 积分条（4 个维度实时更新）**

| 维度 | 权重 | 实时来源 |
|------|------|----------|
| 流利度 Fluency | 35% | 语速 + 停顿频率（客户端实时） |
| 词汇 Vocabulary | 25% | Gemini 音频片段实时识别高质量词汇，结束后复核 |
| 逻辑 Logic | 20% | Gemini 音频片段判断 claim / evidence / example，结束后补全 |
| 时长 Duration | 20% | 本次 session 累计秒数 × 时长乘数 |

> 视觉规则：KTV 条是细、轻、沉浸式状态层，不能做成突兀白卡。每个指标必须显示名称、当前值、变化来源；分数跳动必须和具体事件绑定，例如用了高级词、补了例子、连续说满 30 秒。

**成就解锁（练习中即时触发）**

| 成就 | 触发条件 | 动画 |
|------|----------|------|
| 🔥 On Fire | 连续 30s 无停顿 | 屏幕边缘火焰粒子 |
| 💎 Vocab Star | 单次用了 5+ 高质量词汇 | 钻石爆炸 |
| ⏱️ Marathon | 本次练习超过 3 分钟 | 时钟翻转 |
| 🌟 Evidence King | 引用了 2+ 数据/案例 | 星光散射 |

## 4. 游戏化机制设计

### 4.1 积分系统

```
Session Score = 
  (Fluency Score × 0.35 + Vocabulary Score × 0.25 + Logic Score × 0.20 + Duration Bonus × 0.20)
  × Streak Multiplier (1.0 → 1.5 over 7 days)
```

### 4.2 连续打卡

- 连续 3 天：解锁"Warm Up" 徽章
- 连续 7 天：Streak 乘数达到 1.5x，积分翻倍
- 连续 14 天：解锁"Dedicated Speaker"专属界面皮肤

### 4.3 素材库成就

- 保存 5 个高光片段 → 解锁 TTS 语音包生成
- 复用素材 3 次 → 解锁"Memory Master"徽章

---

## 5. 素材库（Material Bank）

练习后沉淀，按话题 / 时间 / 质量排序。

| 素材类型 | 来源 | 用途 |
|----------|------|------|
| 高光语音片段 | 自动/手动捕捉 | 试听复习 |
| 原始转录文本 | 实时字幕 + Whisper 复核 | 精读、纠错 |
| 润色练习稿 | 结束后 AI 基于原意整理 | 下一次直接跟练、背诵 |
| TTS 语音包（二期）| 用户自己声音合成 | 跟读强化 |
| 话题卡模板（二期）| GPT-4o 生成 | 演讲框架参考 |
