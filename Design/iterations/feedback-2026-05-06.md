## 反馈 #1：字幕改为单行播报

### 原话
> keep the transcript to one line ("only showing the current line"), this can keep the karaoke feeling, while making sure we are not showing users too much information all at once, plus when the transcription is running live and the surrounding has people constantly talking, the "end" button on the top right keeps getting bumped and cannot be clicked

### 核心问题
- 当前字幕多行展示时，信息量过大，用户分心
- 多人环境噪音导致实时转录频繁抖动，右上角 "End" 按钮被挤开无法点击

### 建议方向
- 字幕只显示当前正在说的一行（Karaoke 风格滚动）
- 旧行自然上浮消失，保持界面干净
- End 按钮需要固定位置，不随字幕内容变动

### 对比当前状态
CHANGELOG Sprint 2 已做：字幕框提升到 132px、interim 蓝色高亮。但仍是多行模式。
**需改进：** 从"多行字幕"改为"单行 Karaoke 滚动 + 已说完内容淡出"

## 反馈 #2：去掉音浪

### 原话
> consider not showing the "voice wave", there are a lot of moving elements showing all at once and is a bit distracting

### 核心问题
- 音浪（Canvas 40 柱）+ 字幕 + AI 气泡 + KTV 四指标 + 暂停卡片——动态元素太多
- 6–9 年级学生在开口说话时注意力已高度集中在内容上，视觉噪音过多

### 建议方向
- 说话中仅保留：字幕（单行）+ 话题提示 + 静默计时
- 音浪降级为极简麦克风指示器（一个小呼吸点即可）
- KTV 指标可在暂停/结束后展示，说话中不需要

### 对比当前状态
CHANGELOG Sprint 2 已做：音浪移到底部，成为持续麦克风同步反馈。
**需改进：** 从"动态音浪"降级为"极简呼吸指示器"

## 反馈 #3：说话时显示话题提示

### 原话
> if there are additional space/features we wanna implement when users are speaking, maybe think "what could help users better speak about the topic"? for example, showing the topic at the top~ While people are speaking, they could lose their train of thought, and also when first started speaking, they could run into a cold start and not remembering all the details about the topic (especially if it's about unfamiliar things like tech/science)

### 核心问题
- 用户开始说话时容易冷启动——忘记话题细节
- 说话中途容易断线——忘记自己在讲什么
- 科技/科学类话题对 6–9 年级学生本身就不熟悉

### 建议方向
- 页面顶部固定显示当前话题标题
- 冷启动时显示 3–5 个关键词提示（小标签）
- 已说过某个关键词可微变颜色，形成"我讲到了"的成就感

### 对比当前状态
CHANGELOG Sprint 2 已做：Phrase Spark 高亮词 + 停顿追问基于相关 topic。
**需改进：** 新增说话中持续可见的 TopicHeader + 冷启动关键词提示

## 设计原则

三个反馈指向同一个核心——**「说话中的界面，只放帮用户继续说的东西。」**

| 保留 | 去掉/降级 |
|------|----------|
| 单行字幕（正在说） | 多行字幕（历史） |

| 冷启动关键词（帮我开口） | 四指标涨分（说话中不关心） |
| End 按钮（固定位置） | — |

## 反馈 #4：结束页报告改为自上而下 + 引用原文证据

### 原话
> Trying to build the report more top-down & showing some visual evidence if trying to expand more on advices. For example, structured bullet points summarizing what the users talked about during the practice, then pull evidence from there.

### 核心问题
- 当前 Takeaway 的建议缺乏与用户实际说话内容的直接关联
- 用户看不到"建议我这样做，是因为我刚才说了这句话"的因果链

### 建议方向
- 报告结构：先说「你讲了什么」（结构化摘要 + key points）→ 再给「基于此的建议」
- 每条建议附带原文引用（高亮片段），形成"你说 → 所以建议"的视觉链

### 对比当前状态
CHANGELOG Sprint 2.2 已做：Next Run Plan 改版。
**需改进：** 每条建议需要附带原文引用

## Design Walkthrough PDF — 2026-05-06

> 来源：SpeakSpark Labelled Design Walkthrough（7 页 PDF，截自线上界面 + 标注）
> 核心立场：**Position SpeakSpark as a private practice coach, not an evaluator.**

### Page 1 — Cover
- PRIMARY RISK: The UI can accidentally read as scoring, judging, or contest preparation.
- LAUNCH RULE: Coach process only — prompts, frames, vocabulary choices, one next-run plan.
- AVOID: Full speeches, contest scores, ranking language, real-time error marking, provider-specific AI errors.

### Page 2 — Start Screen
| # | 问题 | 修复方向 |
|---|------|---------|
| 1 | Streak language creates pressure | 用 "5 practices this week" 替代 streak 作为情感钩子 |
| 2 | "92 pts" reads like a score | 替换为学习证据："2 phrases saved", "1 coach note" |
| 3 | CTA "Start Speaking" competition-adjacent | 测试 "Start Practice" 或 "Practice this topic" |
| **方向** | 首屏应该是选择练习话题 + 复用已存短语，不是挣分 |

### Page 3 — Practice Screen
| # | 问题 | 修复方向 |
|---|------|---------|
| 1 | "Antonens" vague and score-like | 重命名为 "coach notes" 或移除 |
| 2 | Metric panel feels like live judging | 说话中隐藏详细指标，结束后作为 private evidence 展示 |
| 3 | "AI is listening" surveillance-like | 改为 "Coach is following your practice" / "I am following your idea" |
| 4 | Loading state blocks practice promise | 允许先录后生成 coaching，不让 AI 就绪成为用户的阻塞 |
| **方向** | 说话中只显示 timer + End + calm coach status + voice wave + save phrase |

### Page 4 — Takeaway Top
| # | 问题 | 修复方向 |
|---|------|---------|
| 1 | Trophy implies winning/ranking | 替换为 notebook/check icon + "Practice complete" |
| 2 | Stats row looks like report card | 先显示一句人话 "You kept your idea going for 41s!" |
| 3 | Best product value not first | Next Run Plan 应该是每次练习后的 hero card |
| 4 | Red AI fallback feels like failure | 改为中性文案 "Coach plan is ready from this run" |
| **方向** | 结束后第一刻应该回答一个问题：what should I try next? |

### Page 5 — Takeaway Lower
| # | 问题 | 修复方向 |
|---|------|---------|
| 1 | Prompts can encourage full-answer generation | "Go deeper" → "Ask me one question"，避免生成完整答案 |
| 2 | Progress map returns to score framing | 用文字趋势："clearer claim", "more examples", "longer opening" |
| 3 | Practice again CTA is strong | 保留 — 支持核心循环：practice → one next move → practice again |
| **方向** | 加持久标签 "Coach mode: practice feedback only"，阻止完整演讲生成 |

### Page 6 — Growth Page Top
| # | 问题 | 修复方向 |
|---|------|---------|
| 1 | Growth map is the right frame | 保持个人成长语言，避免公开排名 |
| 2 | Trying Point is excellent | 推广这个概念到全 app，降低焦虑 |
| 3 | "Ability Portrait" feels like scorecard | 重命名为 "Practice growth"，偏好叙述证据 |
| **方向** | 用 growth page 语言作为全产品模型：one private upgrade at a time |

### Page 7 — Growth Page Lower
| # | 问题 | 修复方向 |
|---|------|---------|
| 1 | Practice history is useful evidence | 保持 history 聚焦练习动作 |
| 2 | "User management" sounds internal | 重命名为 "Settings"（B2C 面向学生/家长） |
| 3 | Coach mode should be more explicit | "Gentle prompts" → "Practice feedback only" / "Contest-safe coaching on" |
| **方向** | 把安全边界作为产品实力暴露——不是限制，是信任的理由 |
