- **Say it like this 未改 AI prompt / 数据结构**：句式用静态精选库（`SENTENCE_FRAMES`），词汇升级直接复用 AI 已产的 `reuse_words`（"弱词→强词"格式），怎么展开用静态骨架。**好处**：零 token 风险、AI 失败也不空（本地兜底已含这些字段）。若以后想让 AI 现填更贴个人的句式，再按原 spec 加 `say_it_like_this` 字段。
