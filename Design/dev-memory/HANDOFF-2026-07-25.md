## What this is
**SpeakPeak** (product renamed from SpeakSpark; `speakspark` still appears in
code/storage keys — that's fine, don't mass-rename). Mobile-first web app: a
real-time English **speaking / debate practice coach** for Chinese grade 6–9
students. Owner-led validation toward the first paying user.

Stack: Vite + React 18 + TS + Tailwind + shadcn/ui. HashRouter. State in
local/sessionStorage (no DB). AI via a Supabase Edge Function proxy
(`callGeminiProxy` → gemini-2.5-flash). iOS STT via Deepgram Nova-2.

## 🔧 In-flight work: Takeaway 复盘页 4 fixes (PARTIALLY DONE)

Owner feedback (2026-07-13). Full spec:
**`Design/specs/2026-07-13-takeaway-fixes.md`** — read it, it has the why + exact plan.
All work is in **`src/pages/TakeawayPage.tsx`**. TL;DR of the 4 issues:
1. **Words** shuffle only reorders the same 3 → page through a bigger pool.
2. **Sentences** pastes irrelevant famous quotes → replace with 3 savable rewrites
   of the student's OWN sentence.
3a. **Coach** questions too generic → AI-generated questions grounded in the talk.
    (Decided: **NO LangGraph/LangChain** — it's a prompt/context problem, and there's
    no server to run a graph on; conflicts with "freeze self-hosted backend" strategy.)
3b. Takeaway **regenerates on every remount** → cache by session signature.

### ✅ DONE (committed, compiles clean)
Backend/schema layer only:
- `AiTakeaway` interface += `base_sentence`, `sentence_rewrites[]`, `follow_up_questions[]`.
- `normalizeList(value, fallback, max=4)` now takes a max; `normalizeTakeaway` parses
  the 3 new fields and raises `reuse_words` cap 4→10.
- `createLocalTakeaway` (offline fallback) returns the 3 new fields.
- `buildTakeawayPrompt` + the JSON schema block ask the model for 6–10 `reuse_words`,
  `base_sentence`, 3 `sentence_rewrites`, 3 `follow_up_questions` (all grounded rules written).
- Persistence scaffolding: `TAKEAWAY_CACHE` key, `TakeawayCache` interface,
  `sessionSignature()`, `readTakeawayCache`/`writeTakeawayCache`, `sessionSig` memo,
  and a **cache-HIT guard** at the top of `generateTakeaway` (restores takeaway+chat, skips AI).

### ⛔ PENDING (UI not wired — next agent, start here)
1. **3b cache-WRITE is missing** → cache is read but never written, so it never hits.
   Add `writeTakeawayCache({ sig: sessionSig, takeaway, chatMessages, chatHistory })`
   after the successful AI generate, after the local-fallback path, and update it on
   each turn in `askCoach`. Also add `sessionSig` to `generateTakeaway`'s deps array.
2. **Words UI**: `shownWords` (~L583) still does `sort(random).slice(0,3)` and the
   Shuffle button is gated `reuse_words.length > 3`. Replace with a `wordPage` state;
   `shownWords = reuse_words.slice(page*3, page*3+3)` (wrap); Shuffle bumps the page.
3. **Sentences UI** (~L746): still renders `pickStealLines(2)` famous quotes. Replace
   the "Lines from great speakers" block with: `You said: "{base_sentence}"` + map
   `takeaway.sentence_rewrites` to 3 cards, each with a pin that calls
   `toggleLine(rewrite, "Your line")`. Drop the `stealLines` state + `pickStealLines` import.
4. **Coach presets** (~L66 `PRESETS`): build the quick-question chips from
   `takeaway.follow_up_questions` (fall back to 2 static ones if empty).
5. Then `tsc --noEmit` + `npm run build` + deploy + verify in browser (seed demo data —
