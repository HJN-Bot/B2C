# Spec — KTV 指标真实化

> 2026-06-02 · 对应 TODO：P2·KTV · 文件：`src/pages/PracticeRoom.tsx` · 状态：✅ 已实现 🧪 待验证

## 修改建议
四个 KTV 指标（Flow/Words/Sentences/Story）只有 Sentences 会动，其它极慢，story 不知怎么算，没有"为什么涨"的感觉。要让四个都能随我说的内容实时、可解释地涨。

## 解决思路
现状：flow/story 只在 Gemini 分块返回时涨（稀疏）；words 靠高光；sentences 靠本地句型识别（所以只有它常动）。
→ 在本地（节流的字幕分析里）补上 flow / story 的**内容相关本地涨分**，每次都带原因，和现有 `latestKtvEvent`（"+2 X · 原因"）一致。各指标的含义已有 `purpose` 标签（keep talking / strong phrases / better forms / complete point）。

## 技术方案
1. 新增冷却 ref：`lastFlowBumpAtRef` / `lastStoryBumpAtRef` / `prevAnalysisLenRef`。
2. 节流分析块内：
   - **Flow**：transcript 比上次分析变长（持续在说）且距上次 flow 涨 ≥3s → `bumpKtvScore("flow", 2, "Kept your idea going")`。
   - **Story**：tail 命中连接词（because / so / for example / this shows / as a result / therefore / which means…）且距上次 ≥5s → `bumpKtvScore("story", 3, "Connected an idea")`。
   - Words / Sentences 维持现有触发。
3. 涨分视觉沿用现有（bar `transition-700` + `activeKtvMetric` 高亮 + `score-jump`）——已算丝滑，不另改。

## 验证测试
tsc + build；手动 `#/practice`：连续讲 → Flow 持续小涨（"Kept your idea going"）；说到 because/for example 等 → Story 涨（"Connected an idea"）；四个指标都动且每次有原因。
