> 关联：[say-it-like-this v2 §5](./2026-06-24-say-it-like-this-v2.md)、`lib/trying-point.ts`

## 想解决的问题（假设）
结果页给了金句/词汇升级，但**看完就忘**，下次练习用不上。如果能让用户在结果页**📌 pin** 几句喜欢的，下次进练习页（开录前）它们就摆在眼前，提醒"这次试着用上"——把"学到 → 用上"的闭环接起来。

潜在价值：① 提高再次练习的动机 ② 真正发生语言迁移（用上学到的）③ 让抽象的 trying point 落成**具体可照搬的句子**。

## ⚠️ 为什么可能"不需要"（先自我反驳）
- 我们刚在做**减负**（测试说报告太长），pin 又加 UI 复杂度。
- 已有单个 trying point 带到首页；再 pin 多句可能**稀释焦点**。
- 录音时用户不看屏（反馈⑤）→ 只能在**开录前**展示，他到底会不会读？
- n=1 还没验证用户有这个需求——别过早造功能。

→ 结论：**做就做最小版，且用最低成本验证**，不一上来就做花哨。

## 最小设计（v1）
1. **数据** `src/lib/saved-lines.ts`（仿 `trying-point.ts`，localStorage `speakspark.savedLines`）：
   `SavedLine { id; text; kind: "frame" | "word" | "sentence" }`；`add/list/remove/clear`；**上限 5、去重、FIFO**。
2. **结果页 pin 入口**：Level up 里的 🧱 Sentences 金句、✨ Words 升级词，每条加一个**小 📌 切换标**（点亮=已 pin，再点取消）。低调、不抢视觉，不打断阅读。
3. **练习页开录前 Ready 卡**（P0 那张）：若有 pin 内容，加一小块 **"Lines to try"**，列出 pin 的句子（只读 chip，可单条移除）。**只在开录前显示，录音中不变**（守反馈⑤）。
4. （Phase 2，可选）**用上即奖励**：若本次转录里检测到 pin 的句式 → 高光庆祝"你用上了自己 pin 的句子 ⭐"。这是最强的正反馈，但先不做。

## 待定（动手前要拍的）
- pin 显示位置：放进 Ready 卡内（可能挤）vs Start 按钮下方一条可收起的小条？
- 哪些可 pin：只 Sentences 金句，还是 Words / "你的句子升级版"也能 pin？
- 上限/过期：留最近 5 条？用过自动清掉？
- 要不要 Phase 2 的"用上即奖励"？

## 怎么低成本验证"要不要做"
- 先只做 1（数据）+2（pin 入口）+3（Ready 卡显示），**不做奖励**。
- Owner 自己用几次：pin 完下次练习**会不会真去看/用**。会 → 继续打磨；不会 → 砍掉，回退成本极低（一个 lib + 两处渲染）。
- 等埋点上线后看：pin 的句子在后续 session 的转录里复现率。
